# 跨KU（知识单元）关联分析方法（人工审订版）

来源：上传同名规则的关联矩阵、LINK-01至LINK-06、综合与检查清单。本版撤销状态组合自动生成因果、固定附加温升与统一操作顺序。

关联候选用于定位问题，不是已成立的因果规则。检查两侧的对象、测点、时间、工况、物理量、适用依据和实际正文。同一设备不同条件允许不同结论；相同数据也可能被共同误解。

| 候选关系 | 要核实的条件 |
| --- | --- |
| 谐波—电容—发热 | 实际投运、谐波频谱、阻抗及设备参数；不能只由THDu推出谐振、爆炸或固定附加温升 |
| 负荷—发热 | 同期负荷、设备部位和散热条件；不能把一个测点结果外推全部设备或未来工况 |
| 剩余电流—保护 | 测量范围、比例分母、保护投退与动作特性分别核实；未知投退不能写成无保护 |
| 接地—剩余电流 | 实际接线与测量路径；接地缺陷和剩余电流同时存在不等于已确定根因 |
| 电压事件—SPD | 区分暂态浪涌、电压暂降、持续暂升及中断；SPD不等同抗暂降或恢复供电设备，不能合并成同一响应链 |
| 供电路径—切换 | 真实备用路径、负荷要求与切换记录；不能无依据估计分钟/小时/秒级恢复时间 |
| 环境—局放 | 同对象环境与检测证据；缺局放数据不能推定局放已异常 |

技术/安全硬性前置与资源协调建议分开。硬依赖必须说明为何后项在前项未满足时不能实施，并给出处置依据；相关、同一计划或共用管理制度不够。资料不足时列待核实条件，不凭模板要求先停用、再投运、再更换或固定维修顺序。
