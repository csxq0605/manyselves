# Manyselves brand system

## Identity

- Product name: **Manyselves**
- Tagline: **One runtime. Many selves.**
- English descriptor: **A local workspace for document-defined agent teams.**
- Chinese descriptor: **由文档定义 Agent 团队的本地工作空间**

Use **Manyselves** for all visible product names, window titles, package
metadata, screenshots, and general documentation. Use sentence case for
headings. Do not shorten the name to “Many”, “MS”, or “ManySelves”.

## Product boundary

Manyselves is the reusable local runtime and workspace. A particular Agent team
is a capability loaded into that runtime. The included power-distribution report
team may be described as “bundled”, “included”, or “current”, but must not define
the product category.

## Canonical technical names

The maintained names are:

- `manyselves` Python import namespace;
- `manyselves.config.yaml` configuration file;
- `.manyselves` project-local state;
- `manyselves` primary CLI command.

No former product name may appear in maintained filenames, Python imports,
configuration, state directories, screenshots, or examples.

## Mark

The four facets represent distinct identities arranged around one shared
workspace. The empty center is intentional: the runtime supplies structure while
the team's documents supply its identity. Avoid power, laboratory, robot, face,
formula, and document-sheet symbols in the product mark.

Primary assets live under `assets/brand/`; deterministic exports are generated by
`scripts/build_brand_assets.py`.
